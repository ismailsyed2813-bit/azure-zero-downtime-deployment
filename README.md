# Zero-Downtime Deployment & Automated Rollback on Azure

## Project Overview

This project demonstrates automated application deployment and rollback using Microsoft Azure.

## Technologies

* Azure App Service
* GitHub Actions
* Azure Bicep
* Azure Application Insights
* Git and GitHub
* PowerShell

## Project Goals

* Build and deploy a web application.
* Automate CI/CD using GitHub Actions.
* Deploy new versions through a staging environment.
* Validate deployments using automated health checks.
* Implement a rollback mechanism for failed releases.
* Monitor application health and errors.

## Current Status

Version 1 application development.
